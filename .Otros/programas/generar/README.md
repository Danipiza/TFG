# Programas para generar los _datasets_

### [genera_puntos.py](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/generar/genera_puntos.py)
Genera individuos en un espacio d-dimensional en unos intervalos marcados por inicialización. Almacena los individuos en un fichero de texto.

### [generaArray.c](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/generar/generaArray.py)
Genera arrays ordenados o no ordenados, con/sin repeticiones. Almacena el array en un fichero de texto.

### [generaMatriz.c](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/generar/generaMatriz.py)
Genera y almacena matrices dando el número de filas y columnas.

# Otros programas 

### [maze_generator_c.c](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/generar/maze_generator_c.c)
Programa creado por [ChlouisPy](https://github.com/ChlouisPy/maze-generator-maze-solver). He cambiado un poco el programa para poder crear los ficheros de forma más eficiente.

### [shuffle.py](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/generar/formato_ficheros.py)
Programa que sirve para barajar los individuos de una población almacenada en un fichero de texto.
