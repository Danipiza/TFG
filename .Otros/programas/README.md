### [ejecuciones.py](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/ejecuciones.py)
Programa que sirve para imprimir por una interfaz unas pruebas almacenadas en unos ficheros de texto.

### [files.py](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/files.py)
Programa que sirve para juntar varias pruebas almacenadas en distintos ficheros de texto. La salida es otro fichero de texto, el cual es usado para generar las gráficas de LaTeX.


### [formato_ficheros.py](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/formato_ficheros.py)
Programa que lee unos ficheros de texto y ejecuta multiplicaciones o divisiones para cambiar el formato de los números almacenados en los ficheros.


### [speedup.py](https://github.com/Danipiza/TFG/blob/main/.Otros/programas/speedup.py)
Programa que sirve para crear ficheros para las gráficas _speed-up_ de LaTeX. Lee dos ficheros para realizar el cálculo del _speed-up_.
